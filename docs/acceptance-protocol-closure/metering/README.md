# Offline metering closure

`protocol.mjs` is an additive adapter. It does not replace a live driver, import
private configuration, authorize larger caps, or dispatch providers. The corrected
full success plan is 77 target / 50 Gateway / 10 Naive HTTP operations. Approved
limits remain 32 / 16 / 0, zero cloud mutations and 180 seconds. The deficits are
45 / 34 / 10. Factory admission fails before accessing `privateRuntimeRef`; even
passing the larger plan numbers is rejected as changed authority.

All twelve frozen Text cases and their original 24 rubric checks per pass are
retained in the plan. One Text reproduction adds one target and two judges. Two
full Calendar passes add 48 target dispatches, and two Calendar reproductions add
four. Three report tasks remain included. No selected Calendar smoke is called
full acceptance. The plan assumes authentic retained suite design/review and one
investigator + one engineer task completing immediately; any extra provider poll,
retry, recovery or missing design adds calls and requires a revised approved plan.

The journal reserves before dispatch, fsyncs rows under an exclusive local lock,
refuses dispatch replay after restart, and retains unknown cost holds. Observation
retries are idempotent only when the entire observation matches. Unknown cost is
represented separately from the sum of known actual observations, so a known-cost
sum of zero does not mean the operation was free. Actual input/output token counts
are observation fields; request ceilings do not become reported usage or bills.
Actual cost exceeding a reservation remains recorded and stops subsequent dispatch.
Receipt IDs cannot be reused across attempts. Receipts here must already have
been authenticated by the owner provider adapter: receipt ID strings do not prove
provider provenance. Unknown observations are immutable and require separate owner
reconciliation; this artifact never releases holds or settles billing.

These local journal tests do not establish hosted transaction durability, provider
receipt authenticity or a complete monetary ceiling. `costEnvelope` returns only
900,000 + twice contextBound + 50 judge holds + 12 remediation holds, plus explicit
unknown baseline/reproduction/Calendar pricing, input usage and retry costs. The
12,800 Text / 102,400 Gateway requested completion token ceilings are not usage.

Remaining hosted gates: independently approved operation/monetary plan, actual
proposal and server-approved prompt hash, provider pricing and usage receipts,
server phase/judge policy, hosted transactional reservation/restart/concurrency,
private report and SQL identity proofs, credential/auth validation, production
build and explicit hosted/provider execution approval. No gate is satisfied by
this offline adapter. No credentials, providers or cloud resources were accessed.
