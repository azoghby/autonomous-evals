## Concrete execution

`createMultimodalBridge` is the public factory. Bind it to the already admitted suite, approval, isolated trial/run, runtime version and exact target/media configuration digests. Its mandatory `authorize` rechecks caller authority on every invocation, including completed replay. Runtime provisioning, frozen fixtures, final SQL snapshot, grading, disposal and TTL recovery stay with the existing engine/runtime owners. Media evidence is supplemental; it cannot produce an overall passed trial, a settled legacy `TrialResult`, or prove final state correctness.

- `voice(input,run)` composes A `speakAsPersona`, `transcribeAudio`, `ChatAudioVoiceDriver`, WER and perception. An actual SDK speech request produces WAV, an independent SDK transcription reads that WAV without expected text/facts, then the actual A chat-audio driver serializes binary input. Target completions are capped at 1,000 tokens with parallel tools disabled. Tool rounds execute sequentially through the supplied real isolated `run.callTool`; actual tool identity/arguments are checked. Final audio is independently transcribed even if the target asserts its own transcript. Input oracle disagreement, missing audio, duplicate calls, bounds, warnings and aborts fail closed. TTS/STT/target models are explicitly configured; STT and target identities must differ. Whole-response TTFA is an upper bound, never streaming latency.
- `receiptChat(input,config,run)` renders an actual deterministic receipt PNG through A `materializeAttachment`/sharp. A `runMediaOracle` receives binary pixels and field names, never expected values; its extracted values must agree with nonempty known ground truth. The oracle and target models differ. `createReceiptChatTarget` serializes PNG `image_url` data and executes declared, schema-validated tools through the actual supplied isolated run. Perception checks use actual tool records and transcript. Target model, delivered asset digest, target config, original truth and latency are retained. Factory checks the concrete target config digest against the server-held binding before execution.
- `receipt(input,target)` supports an existing trusted binary-capable target port. The owner must bind its actual config/model and delivered bytes, validate tools, enforce secrets, and retain real records; arbitrary customer functions or model assertions are not authority. Missing binary transport is explicitly unsupported.

Lower-level leaves are exported for composition/tests. Call them only behind the factory's whole-trial fence or an equivalent durable authority. Transport fences alone cannot prevent repeating stateful tools. Supplied tools must validate input schemas, enforce row/tool policy, and correctly mark executed/fault outcomes. No factory takes runtime functions from customer JSON.

## Durable authority, budget and secrets

`createMediaTransport` requires explicit fetch, exact approved HTTPS URLs, authorization, credential resolver, secret inventory, permanent dispatch authority, mandatory meter and finite request/response/time/reservation bounds. Missing fetch is unsupported. Non-JSON/streaming request bodies are unsupported. Redirects are refused, HTTP/provider errors are sanitized, response streams are read under byte/time limits, and noncooperative fetch is deadline-bounded. Only bounded JSON reaches SDK parsers. Known plaintext/JSON-escaped/URL-encoded/base64 secrets are rejected in requests and responses; raw media bytes are private and not report attachments. Semantic secrets spoken in audio require the independent transcript checks and a complete owner-supplied secret inventory, not byte scanning alone.

Each network operation claims durable identity before reserving against the common job/trial/global budgets. `meter.reserve` MUST atomically authorize/fence conservative worst-case money under those SAME scopes; it must refuse absent budget. `observed` retains digest/byte/latency evidence; private journal response bytes permit authoritative usage reconciliation. This interface does not implement billing or accept list-price estimates as settlement. All public trial artifacts retain `{status:'unknown',microUsd:null}`; numeric zeros required by A compatibility types never escape as settled cost. Ambiguous reservations/dispatches remain held. Never implement these production hooks as no-ops.

`FileMediaAuthority` implements actual single-host disk replay: permanent atomic directory claims, private file permissions, fsync of identity/directories, fsynced result and atomic rename. Completed results replay from disk after reconstruction. Pending, conflicting, failed or ambiguous operations never automatically redispatch. Whole-trial artifact persistence fences target/tool effects separately from network dispatch. Factory hashes approval, suite/env/runtime/config pins with trial input; changed bindings conflict. Secret-bearing or oversized artifacts cannot complete. Abort/deadline after an unabortable tool means unknown state requiring reconciliation, not rollback or permission to retry.

Use a private trusted root owned by the worker; journal files contain media/provider response bytes and must receive platform retention/encryption controls. This is single-host filesystem durability, not distributed SQL acceptance. Production must provide equivalent atomic shared authority, owner-only storage and crash reconciliation. Private asset publication/signed URLs are not implemented; current delivery is bounded in-memory binary data only.

## Target transport is a separate boundary

`createPinnedTargetFetch` composes the existing `targets/transport.HttpsJsonTransport`: public DNS validation and address pinning, TLS host verification, no redirects, no proxy/pooling, bounded request/response/concurrency/deadline. It is intended for customer chat targets and preserves standard JSON/body/bearer semantics. It does not carry SDK-specific Gateway headers, so do not use it for native Gateway requests. Gateway fetch must be separately secured/allowlisted by the platform; there is no implicit default network fetch. Both are wrapped by the durable/metered `MediaTransport` boundary. Injected test transports never perform network IO. Tests separately reject private resolved DNS and invalid target URLs before network dispatch.
