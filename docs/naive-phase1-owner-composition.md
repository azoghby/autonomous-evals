## Rich assessment and provider requirements

The adopted `RunResult` contract now represents objective, rubric, inconclusive and infrastructure assessments explicitly. Only complete objective checks with pass/fail statuses publish a boolean. Rich retained artifacts remain the investigation authority; public projections do not grant approval. Malformed objective concerns and inconsistent execution/target states reject. Progress and relevant public consumers distinguish unresolved/rubric states from objective failures.

The current rich and public finding labels also lack a dismissed/resolved lifecycle state. A rerun can retain Ines's explicit relabel decision, but cannot publish a dismissal by pretending it is inconclusive. The adapter blocks that public projection with `needs_operator`; Track A must extend the finding lifecycle contract and its consumers before resolved-finding acceptance can pass. Do not count this as full rerun support merely because the factory exposes the method.

Injected rubric judges are not automatically Naïve. `judges/naive-proxy.ts` now supplies the plan's Jude proxy alternative with durable request fencing, exact-quote validation and SDK billing-trace reconciliation. `judges/naive-proxy-service.ts` now constructs it with the actual ServiceContext cost callback and validated `naive_proxy` receipts; operationId supplies canonical purpose. The adopted expert text runtime wires this factory with `createNaiveProxyBudget` and the shared SQL ledger; other paths must do the same. Objective checks remain authoritative. It requires `proxy:write` and `audit:read`, a configured model/input-price policy, and an atomic `naive_proxy` cost sink. The SDK has no monetary cap for proxy calls; reservations are local admission bounds, not guaranteed provider ceilings. The factory does not certify outcomes, files or all roster roles merely by importing a module. Text adapters do not implement workflow or version-comparison package semantics; those need explicit mappings with retained authority and parity evidence.
