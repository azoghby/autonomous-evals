# Capability matrix

| Capability | Executable now | Initial setup / remaining gate | External or human exception |
|---|---|---|---|
| Authority | Immutable policy, exact agent identity/version, current guard checks, durable reasons | Server-only policy storage and exact directory wiring | Policy/budget changes are setup authority only; no agent escalation |
| Intake and quote | Actual Commercial service, bounded customer clarification, fixed price menu | Authenticated intake and reply correlation | Customer answer, authorization or scope choice is external |
| Payment | Driver waits authoritative paid receipt | Existing signed Stripe webhook/reconciliation adapter | Customer checkout; invalid/ambiguous financial receipt pauses |
| Agent execution | Existing durable SQL session service plus policy envelope and root/role atomic budget adapter | Provision verified pinned Naïve agents; authentic credentials | Unreconciled paid create or unknown usage remains exception |
| Data acquisition | Bounded discovery/generation callbacks, durable claims/cost records, deadline, restart recovery | Configure budgeted source/generation adapters; authenticated retrieval/permission receipts | Unknown permission/unsupported facts end not assessed |
| Independent data admission | Exact question/context/evidence/permission bindings and producer/checker separation | Trustworthy source registry and deterministic fact catalog | No fabricated expert identity, consent or human review; arbitrary facts unsupported |
| Expert contact | Configured recipient/consent decision + guarded outbox request once | Approved recipient, consent policy, inbound contribution adapter | Expert answer is external; no response ends not assessed |
| Text evaluation | Actual 12-scenario design, independent review, freeze, execute/investigate | Owner durable target/judge adapters and budget admission | Fixture objective results only; missing judge explicitly unassessed |
| Report | Real JSON/Markdown/HTML renderer, durable publication before report-ready outbox | Expose/map stored publication through owner authenticated report route | No production publication or customer validation established |
| Notifications | SQL outbox, current sender/contact/claims/secret guards, opt-out, caps, idempotency and receipt recovery | Configure legitimate sender, recipients, provider transport and receipt API | Unknown dispatch pauses; transport omitted in offline setup |
| Monitoring/retests | Consent-bound fixed-price offer; existing owner services remain separate | Owner comparison/monitoring/retest integrations and actual subscription consent | Customer subscription/payment; no automatic charge here |
| Recovery | Bounded action lookup/deadline, no duplicate dispatch from acquisition/company effect claims | Periodic scheduler + authoritative provider adapters | Missing authoritative receipt finishes inconclusive/exception; no blind retry |
| Daily audit | SQL supervisor decision audit view + bounded server scheduled tick | Owner cron auth and persistent operator surfacing | Financial/refund or security exceptions retained for authorized human handling |
| Production release | New applyable server adapter, strict check + offline tests | Owner app wiring, hosted SQL contention, Workflow build/replay, authentic payment/target/inbox acceptance | Not a claim of generally autonomous production operation |

No routine per-job founder approval is introduced in the autonomous fixture path. Human-only legacy review remains compatible and distinct. Initial service-account, source/license, policy and budget configuration cannot be delegated to untrusted customer/model content. Refunds remain proposal/handoff; no automatic transfer occurs.
