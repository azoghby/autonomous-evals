## Hidden caller incompatibilities to fix in slice 3

`designSuiteStep` currently appends `rt_*` red-team cases **after** design/admission. Rich adapters compare the exact retained frozen suite; mutating its public projection then passing it to run is invalid. Move approved red-team generation into pre-freeze design/review, or keep a separately admitted suite/run; do not weaken restoration checks.

`runSuiteStep` currently overwrites public `suite.versionLabel` with the selected run label (`default`, `A`, `B`). Preserve the admitted suite identity; supply run/target version through trusted owner resolution. Text-only investigation currently accepts exactly one retained baseline; the version-comparison caller supplies two. Do not claim comparison support by routing that caller through a text adapter.

The rich design adapter accepts only `text_eval`. Workflow and version comparison need explicit package implementations, retained isolated state and package parity evidence. Leave those capabilities explicitly unavailable for selected Naïve execution until ready. A routing flag is not permission to substitute text semantics.

The current generic finish path automatically proposes fixes for confirmed findings. Routing design/run/investigation alone does not complete a generic job if selected remediation is unavailable. Scope preview acceptance explicitly to supported methods, or install slice 4 before claiming end-to-end generic text completion.
