# Generic text composition candidate

> Development slice only. The current combined adoption candidate is [naive-generic-text-adoption-integration](../naive-generic-text-adoption-integration/README.md). That artifact includes later integration fixes and portable package imports; do not apply this partial slice independently or treat its earlier validation as current application acceptance.

Slice 2 composes the current paid Workflow's existing rich text engine and concrete contract adapters. It introduces no competing Workflow, approval UI, job lifecycle, tables or migrations. Adopt the exact two `source/` files after the authority and engine admission candidates; sibling runtime imports resolve to those installed files.

`createNaiveTextMethods(ctx, deps)` returns `designSuite`, `runSuite`, and `investigate`. `createNaiveTextMethodBuilder(deps)` provides the routing `(method, ctx)` builder. Remediation/rerun selections fail closed pending their own owner runtimes; non-text packages remain unsupported. No lite fallback is introduced.

Production uses existing server SQL lazily and the same public core `AgentSessionService`, SQL task store and SDK adapter, secured `createTextTarget`, shared Postgres budget ledger, and configured Jude proxy with bounded reservation/output policy. Tests inject SQL, a runner factory constructed with the supplied shared ledger and provider/target transports. Independent design admission comes from `createNaiveEngineAdmissionPolicy`; neither a public Suite nor an agent's approval claim grants authority. Existing exact retained artifacts preserve objective/rubric/inconclusive evidence without flattening it.

The first authorized allocation and each bounded role/task session budget are durably pinned. Restart with lower positive remaining context budget cannot change an existing provider task specification. Agent and proxy reservations keep their canonical shared job/role/Jude caps; a ledger decorator adds the pinned generic allocation as a third scope to the same reservation. This atomically enforces the initial allowance without changing shared scope identities or counting spend twice. Zero/invalid budgets are refused before SQL/default provider builders.

Measured session costs enter a canonical owner/environment cost outbox before post-provider authorization. The runner does not acknowledge costs before the rich engine completes its durable checkpoint. The engine's cost callback retains and delivers through the application's keyed sink; a reconstructed factory drains retained receipts before dispatch authority, even when a job has since been cancelled. This separates measured spend reconciliation from permission to dispatch/publish. Operations reauthorize before dispatch and before publication. Target replies pass through the engine’s secret screening and durable target checkpoint before publication reauthorization, so an in-flight revocation does not discard completed transport evidence. The keyed application sink must retain its existing atomic idempotency behavior.

No external calls, credentials, hosted configuration or database migrations were used. Integrator owns actual source adoption, root typecheck/tests/build, ledger and commit. Candidate-only validation is recorded below after completion.
